Day-to-day use: workspaces and the projects that group them, the runs that change them, the variables that carry credentials, environments and promotion, the state Opsolete keeps for every workspace, and running Terraform from your own machine. Then what users can deploy: templates that pin an approved Terraform module and generate its form, the builder admins use to write them, the private module registry those modules live in, and the VCS providers that feed both.
