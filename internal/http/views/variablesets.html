Variable sets

Variables shared by many workspaces, such as a subscription's credentials. A set applies to every workspace that isn't linked to a repository (global) or to the workspaces and projects it's attached to. A repository-linked workspace runs code its users chose, so it only gets sets an admin attached to it, not global or project sets; changing its repository or branch detaches them. A workspace's own variables override sets, sets attached to the workspace override its project's, and those override global ones.
