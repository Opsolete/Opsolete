Variable sets

Variables shared by many workspaces, such as a subscription's credentials. A set applies to every workspace that isn't linked to a repository (global) or to the workspaces it's attached to. A repository-linked workspace runs code its users chose, so it only gets sets an admin attached; changing its repository or branch detaches them. A workspace's own variables override sets, and attached sets override global ones.
